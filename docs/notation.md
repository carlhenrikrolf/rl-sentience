# Notation

- Sets are written in bold, e.g. $\mathbf M$.
- Special sets are written in blackboard, e.g. $\mathbb N, \mathbb Z, \mathbb Q, \mathbb R, \mathbb C$.
- Local functions and variables (i.e. unary function) are written in italic lower-case, e.g. $f(),g(),p,q$.
- Random variables and functions are written as upper case, e.g. $F(), P$.
- Tuples are written as italic bold, e.g. $\boldsymbol f(), \boldsymbol p$.
- Global functions are written in sans-serif, e.g. $\mathsf e, \mathsf \Phi, \mathsf L, \mathsf W$.
- Standard functions are written as e.g. $\log, \exp$.
- Some standard functions are written in blackboard, e.g. $\mathbb P[], \mathbb E[]$.
- Tuples are written as $(\cdots)$.
- Sets are written as $\{\cdots\}$.
- Iverson bracket $[\cdot]$.
- Assignment (definition) is written as $\coloneqq$.
