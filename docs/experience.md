# Experience

**Definition** (agent).
Discrete.
$$A(o^0_t, ... o^{n-1}_t) = (a^0_{t+1}, ..., a^{m-1}_{t+1})$$
- Agent $A$
- observation (input) $o_t$, can also be an observation of internals and an observation of an observation.
- action (output) $a_{t+1}$
Continuous ...

**Assumption** (teleology).
The function of experience is to create an observation $o^i$ that merges other observations $o^{-i}$. (an maybe actions as well).

Motivations.
- You experience both eyes in one experience, there are not two separate consciousnesses for each eye.
